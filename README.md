# DeskTiler — 桌面窗口均匀平铺小工具

一个小巧的 Windows 桌面工具：

- 列出当前打开的所有**应用主窗口**（自动刷新）；主列表为两列：**应用程序** + **窗口标题**（不含 PID）；
- 勾选要整理的窗口后，点击「平铺所选应用」即可把它们在目标显示器的工作区内均匀铺成网格；
- 底部**显示器**下拉可选择平铺到哪台显示器（默认**自动** = 多数勾选窗口所在的那台）；
- 顶部**全选**复选框、**选定窗口置顶 / 本窗口置顶**复选框、表头点击排序、窗口/已选计数；底部五个快排按钮
  （从左到右：目录快排 / PowerShell快排 / Cmd快排 / 应用快排 / 一键全排）；平铺后自动激活所选窗口；
- 列表里**右键任意一行**可以「结束进程」或「转到应用」。

## 运行

直接运行 `DeskTiler.exe` 即可（无需安装，单文件，Win32）。

界面操作：

1. 顶部最左 **全选(&A)** 复选框：打勾=全部勾选、取消=全部取消；逐个勾选列表项时它会自动反映状态
   （全部勾上才显示打勾）。其后是 **刷新(&R)**（重新枚举）与 **自动刷新**（默认开启，每 2.5 秒刷新一次），
   再往后是 **选定窗口置顶** 与 **本窗口置顶** 两个置顶复选框（见第 7 条）；
   右上角实时显示 **窗口总数 / 已选择**；最右上角是蓝色带下划线的 **关于** 链接：鼠标悬停即在其下方
   弹出收款二维码图片（取自程序同目录 `300收款码.jpg`）：**点击图片立即关闭**；鼠标移开约 0.6 秒后也会自动关闭。
   （图片紧贴“关于”链接下缘弹出，鼠标垂直下移即可到达图片上点击。）
2. 点击任意**表头**可排序：第 1 次点升序、再点一次切为降序（表头显示 ▲/▼ 指示当前列与方向）；
   点第 1 列「应用程序」按应用名排，点第 2 列「窗口标题」按标题排；已点过表头后，自动刷新仍保持该排序方式；
3. 在列表中勾选需要整理的窗口（或用顶部**全选**复选框一键勾选 / 取消）；
4. 底部选择 **列数**（默认「自动」，按窗口数、屏幕宽高与空位数自动选择网格）、**窗口间距**（像素）
   与 **显示器**：默认「自动选择」（取多数勾选窗口所在的那台显示器），也可手动点开下拉选中某台，
   此后所选窗口会平铺到该屏工作区（下拉展开时会自动刷新监视器列表，支持热插拔）；
5. 点击参数行右端的 **平铺所选应用(&T)**（主按钮，粗体；原来叫「平铺排列」，动作没变），
   勾选窗口即被移动到目标显示器的工作区并按网格铺开；
   排布顺序为 Z 序自顶向下（最上面的窗口进左上格）。未点过表头时列表也按 Z 序显示；
   排完会**逐个激活**这些窗口（自动还原最小化并置顶），避免被其它活动窗口遮挡；
6. 底部快捷按钮行（从左到右：目录快排 / PowerShell快排 / Cmd快排 / 应用快排 / 一键全排）：
   - **应用快排**（在「一键全排」左边）：先在**列表里点选一行**（该行的「应用程序」即目标），点它就把**同名应用的全部窗口**
     一次平铺（如选中 `explorer` 那行，就把所有资源管理器窗口排开）。选中的行会被记住，
     自动刷新（2.5 秒一次、会重建列表）不会把它清掉，所以点完行再慢慢去点按钮也没问题；
     没有任何选中行时只会提示而不会乱排；
     点选某行后这个按钮会**改成「<应用名>快排」**（点中 `explorer` 那行就显示「explorer快排」，
     一眼看出这一下会排谁），按钮宽度按文字量自适应（量不下就加宽，最长不超过 240px），
     加宽后底行其余按钮自动跟着往左让位，始终不重叠；
   - **目录快排**：一键平铺所有**资源管理器（文件夹）窗口**（判定：进程名 `explorer`，与窗口里开着哪个目录无关）；
   - **PowerShell快排**：一键平铺所有 **Windows Terminal 窗口**（判定：进程名为 `WindowsTerminal` / `wt`；
     终端里跑的是 PowerShell、cmd 还是 WSL 都一样排），另外也认老式控制台窗口（进程名 `powershell` / `pwsh`）；
   - **Cmd快排**：一键平铺所有 cmd 窗口（判定：进程名为 `cmd` / `command`，
     或 Windows 终端里标题含 `cmd.exe` / `命令提示符` / `command prompt`）；
   - **一键全排**（最右端）：把列表里的**全部**窗口一次平铺，无需勾选（兜底那个，放在整行最右端；
     它左边的「应用快排」名字会跟着选中的行走、宽度会变，所以它固定在最右端当锚点）。

   > 界面布局：**平铺所选应用**在参数行（列数/间距/显示器）右端；下面一行才是五个快排按钮。
   > 五个快排按钮的位置由 `LayoutActButtons` 显式计算（不用 alRight 停靠）—— 同一父容器里
   > 多个 alRight 兄弟控件的停靠次序并不等于创建次序，靠停靠会摆错顺序。
   > 「应用快排」改名后宽度会变，那次改动走的也是同一条重排路径（宽度变了就整行重摆一次）。
7. 顶部两个**置顶**复选框（各管一头，互不影响）：
   - **选定窗口置顶**：管**列表里被勾选的目标窗口**。打勾 = 把它们设为置顶（`WS_EX_TOPMOST`，浮在所有
     普通窗口之前）；取消 = 恢复普通层级。开关打开期间，之后**每勾一行都会立刻置顶**，点**全选**
     也会整批跟着置顶；一个都没勾就打开它只会提示「请先在列表里勾选要置顶的窗口」，不会乱动窗口。
     置顶只改层级，不挪位置、不改大小、也不抢焦点。
   - **本窗口置顶**：管 **DeskTiler 自己**。平铺收尾会逐个激活刚排好的窗口，工具窗口随即被盖住，
     勾上它就一直浮着，方便连着点几次快排。（右键「转到应用」跳去别的窗口时它会先让开一下，
     见第 8 条。）
   - 两者都**不会**被记住：程序重启后回到未置顶状态。

   > 顶栏（全选/刷新/自动刷新/选定窗口置顶/本窗口置顶 + 计数 + 关于）的位置同样由 `LayoutTopBar`
   > 显式计算，理由与上面一样 —— 实测 5 个 alLeft 兄弟控件里，第 2 个创建的「刷新」被摆到了最右端。
8. 在列表里**右键某一行**：弹出的菜单里有两项，作用对象就是**右键的那一行**
   （右键会顺手把选中行**改到这一行**（单选，原先选中的行随即取消），于是「应用快排」的名字
   也跟着走，所见即所指）：
   - **结束进程(&K)**：强制结束**该行窗口所属的那一个进程**（`TerminateProcess`）。
     点之前会弹一个确认框，框里**点名是哪个应用、哪个 PID**，默认按钮落在「否」上，误按回车不会杀人。
     只杀这一行那一个进程，**不会**牵连同一应用开着的其它窗口；进程里没保存的数据会丢，确认框里也写明了。
   - **转到应用(&G)**（加粗的默认项）：把该行窗口从最小化还原、置顶并激活到前台，一步跳过去，
     目标窗口会实实在在露在你眼前。
     勾着「本窗口置顶」时工具窗口本来会一直盖在它上面（置顶窗口永远浮在普通窗口之上，光激活是
     看不见的），所以**只要两个窗口有重叠**，就先把自己最小化让开、再激活目标 —— 从任务栏点回来即可，
     置顶的勾选状态不变；两个窗口错开摆放、本来就不挡路时不会让开，工具窗口照旧浮着。
   - 光标停在列表空白处（没指着任何行）时右键，两项都是灰的，不会误伤别的窗口。
9. 列表是 2.5 秒前的快照：右键后到点菜单之间目标窗口可能已经关掉，所以两项在动手前都会
   **重新核对一次**（窗口还在不在、PID 有没有被新进程复用），对不上就只提示、不动作。

## 命令行自测模式

供自动化验证使用，不弹窗：

| 命令 | 作用 |
| --- | --- |
| `DeskTiler.exe -list` | 把枚举到的窗口写入同目录 `winlist.txt`（`hwnd=pid=应用=标题`）后退出 |
| `DeskTiler.exe -tilefirst N` | 自动勾选列表前 N 个窗口（Z 序最顶的 N 个）并平铺后退出 |
| `DeskTiler.exe -tileapp 应用名` | 平铺全部「可执行文件名 = 应用名」的窗口后退出（自动化验证用） |
| `DeskTiler.exe -sorttest 文件` | 自检：对当前枚举结果按 PID / 应用名做升、降序各排一次，结果写入文件后退出 |

## 构建

需要本机装有 **Embarcadero Delphi 10.3（Studio 19.0）**，命令行直接编译：

```
build.cmd
```

脚本会用 `powershell` 生成版本号与图标、`brcc32` 编译资源、`dcc32` 编译工程。
若 Delphi 装在其它路径，改 `build.cmd` 顶部的 `BDS` 变量即可。

**版本号自增**：每次构建都会先执行 `tools/bumpversion.ps1`，把 `build.number` 加 1，并生成
`uVersion.inc`（Pascal 版本常量）与 `DeskTilerVersion.rc`（exe 的版本资源），版本形如 `1.0.<构建号>`。
构建号在 **窗口标题栏**（`DeskTiler v1.0.x — 桌面窗口均匀平铺`）和 **「关于」悬停小窗的底栏**
（版本 + 构建号 + 构建时间）都会显示，一眼就能确认读到的是不是刚编译出来的那份。
`build.number` 随仓库提交（记录到哪一号了）；`uVersion.inc` / `DeskTilerVersion.rc` 属于生成物，不进仓库。
注意：构建号按“构建次数”自增，编译失败的次数也会占用号段（出现跳号属正常）。

## 说明与限制

- 原需求首选 Delphi + DevExpress(dx)；本机未装 DevExpress，故用**纯 VCL** 实现，同样达到效果。
- 「打开的应用」指**可见、有标题、无 owner 的顶层主窗口**（排除：本程序自身、对话框/弹出层、任务栏工具窗口、DWM 折叠的窗口、无标题/无面积的窗口）。同一程序多开会在列表中显示多行。
- 列表默认按窗口 **Z 序** 显示（顶部窗口在最前）；点击表头后按所选列排序（升/降序）。
- 列表每 2.5 秒自动刷新一次（**整表重建**）：勾选状态与「应用快排」用到的选中行都会**按窗口句柄还原**，
  刷新不会把它们冲掉。刷新期间「应用快排」按钮上的名字只在真正变化时才重写一次，不会每 2.5 秒闪一下。
  （还原的是**哪一个窗口**，不是行号；列表按 Z 序排，期间有窗口开关时行号本来就会整体挪位。）
- 列表是**单选**：右键只作用于一行，选中行也只保留一行。多选对平铺没有用处（排哪些窗口是看勾选框的），
  而多选状态下“右键一行”会变成“往选中集合里再加一行”，看上去就像点了这一行、别的行却亮着。
  右键按在哪一行，是**在消息派发到列表之前**记下坐标算出来的 —— 列表视图收到右键按下时，
  VCL 会先同步把菜单弹起来并进入菜单自己的循环，等菜单关掉才轮到控件的 `OnMouseDown`，
  挂在那里记坐标会整整慢一拍，菜单就作用到上一行去了。
- 计数标签、结果提示采用 **TStaticText**（有窗口句柄，便于自动化校验读取文本）。
- 窗口尺寸为 **820×580**（顶栏要塞下 5 个控件 + 计数 + 关于链接；680 太挤，改名成「选定窗口置顶」后
  左侧链条又长了两个字，于是从 780 再放宽到 820）。
- 「选定窗口置顶」是对**当前列表里已勾选**的窗口生效的动作（外加“开关开着时新勾即生效”），
  程序**不会**在刷新后自动重放；窗口本身是置顶的，刷新列表不会把它变回普通层级。
- 「本窗口置顶」与「转到应用」的取舍：置顶窗口永远压在所有普通窗口之上，工具窗口挡着目标时，
  让用户看见目标的办法只剩“让工具窗口自己收起来”——本程序的做法是最小化，且只在两者确实重叠时才做
  （不重叠就没必要打扰；也不会去改目标窗口自己的层级，那是「选定窗口置顶」管的事）。
- 平铺目标显示器：默认**自动**——取**大多数被勾选窗口所在的显示器**；也可在底部「显示器」下拉手动指定某台，
  所选窗口将平铺到该屏工作区。手动选的屏若被拔出，会自动回落到“自动选择”。
- 以**普通权限**运行时，无法移动**以管理员权限启动**的窗口（系统安全限制，属正常现象）。
- 最小化/最大化的窗口在平铺前会自动还原。
- 右键「结束进程」是**硬杀**（`TerminateProcess`），不是先发 `WM_CLOSE` 等它自己退，所以确认框里
  把“没保存的数据会丢失”写清楚了；同样受上面那条权限限制——普通权限下杀不掉管理员权限启动的进程
  （会给出失败提示，`OpenProcess` 权限不足），这时请以管理员身份运行本工具。
- 判据是**窗口句柄 → PID**：结束的是“这一行窗口当前所属的进程”。同一应用多开时，只会杀掉你右键的那一行
  对应的那一个进程（这正是当初选的语义）；反过来，若某个进程的多个窗口都在列表里，一行一行来就是。

## 目录

```
build.cmd          构建脚本（生成版本号/.ico/.res/.exe）
build.number       构建号计数（每次构建 +1，随仓库提交）
DeskTiler.dpr      工程源码
uMain.pas         主窗体源码（枚举 + 平铺逻辑，UTF-8 带 BOM）
uMain.dfm         主窗体 DFM（资源占位，界面为运行时构建）
300收款码.jpg     收款二维码（点/悬停顶栏“关于”链接时显示的图片，须与 exe 同目录）
DeskTiler.rc       资源脚本（图标 + manifest + 版本信息）
DeskTiler.manifest 程序清单（Common-Controls v6、asInvoker、PerMonitorV2 DPI）
tools/makeicon.ps1 图标生成脚本（构建时自动调用）
tools/bumpversion.ps1 构建号自增并生成 uVersion.inc / DeskTilerVersion.rc（构建时自动调用）
```

> 注意：`uMain.pas` 内的中文字符串需以 **UTF-8 带 BOM** 保存，`dcc32` 才能正确识别；
> `build.cmd` 与 `uMain.dfm`/`DeskTiler.rc`/`manifest` 请保持纯 ASCII（避免不同代码页误解析）。
> `uVersion.inc`、`DeskTilerVersion.rc` 由构建自动生成（纯 ASCII、无 BOM），已列入 `.gitignore`；
> `uMain.pas` 里 `{$I uVersion.inc}` 必须放在 implementation 的 `uses` 之后（const 不能写到 uses 前面）。
