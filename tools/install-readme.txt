DeskTiler @VER@ —— 桌面窗口均匀平铺小工具
=====================================================================

免安装：双击 DeskTiler.exe 就能跑，删掉整个文件夹就等于卸载。

运行要求
  · Windows 7 及以上（32 位程序，64 位系统上照跑）
  · 不需要 .NET、不需要额外运行库（Delphi 静态链接，单文件）

目录里的东西
  DeskTiler.exe      主程序
  300收款码.jpg      鼠标悬停在右上角「关于」链接上时弹出的收款码。
                     少了它程序照常运行，只是悬停时会提示「未找到收款码图片」。
  README.md          完整使用说明（右键某一行 / 五个快排按钮 / 两种置顶 /
                     多显示器指定目标屏 / 命令行参数等）
  安装说明.txt       本文件

上手四步
  1. 列表里勾选要整理的窗口（顶部「全选」可一键勾选）
  2. 底部选列数（默认自动）、窗口间距、平铺到哪台显示器（默认自动）
  3. 点「平铺所选应用」—— 勾中的窗口在工作区里铺成均匀网格
  4. 列表里右键任意一行：「结束进程」或「转到应用」

小提示
  · 放桌面 / 开始菜单：右键 DeskTiler.exe → 发送到 → 桌面快捷方式
  · 「结束进程」会强制结束你在列表里右键选中的那一个进程，点之前会弹确认框
    点名是哪个应用、哪个 PID，默认按钮是「否」，误按回车不会杀人。
    进程里没保存的数据会丢，确认框里也写明了。
